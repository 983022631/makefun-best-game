VOIDLIGHT — Last Beacon: a neon arena survival shooter. The beacon is dying — fly its last ship through 10 waves of rocks, drones and weavers, draft an upgrade after every cleared wave, and destroy the Dreadnought boss on wave 10 to save the light. Combo scoring, salvage pickups, hull and regenerating shield, a dash with i-frames, synthesised WebAudio sound, pause, game-over and victory screens, and a best score kept in localStorage. Static files, no build step, no network request.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. WASD / arrows to fly, mouse to aim, hold click to fire, Shift to dash, P to pause, M to mute. Clear a wave, draft an upgrade (click a card or press 1 / 2 / 3), survive all ten.
